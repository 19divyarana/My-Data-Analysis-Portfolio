## IPL Data Analysis using SQL (MySQL)

## Project Overview
This project analyzes IPL cricket data using SQL queries in MySQL. It focuses on player performance, match results, and game trends.

## Tools Used
- MySQL 8.0
- MySQL Workbench
- Kaggle IPL Dataset

## 📂 Dataset
Dataset used: IPL Complete Dataset (2008–2024)

Source: Kaggle  
Link: https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

Note: Dataset not uploaded due to size limitations.

## 📊 Key Analysis
- Total matches and seasons
- Top batsmen and bowlers
- Strike rate and economy rate
- Toss impact on match result
- Runs analysis by over phase

## 🔥 Key Insights
- Top batsmen contribute majority of runs
- Teams winning toss often win matches
- Death overs (16–20) have highest scoring
- Certain venues produce high-scoring games

## ⚙️ How to Run
1. Run `schema.sql`
2. Import CSV files into tables
3. Run `queries.sql`
